# Hints and extensions

## Hints

Stuck on a lab task? **Hint** reveals the task's next hint. Hints come in order, and only for the task you are on.

A hint can cost points. The button shows the price (*−2 pts*, or *free*), and Crucible asks before revealing a hint
that costs something. The lab sets a price for all its hints, and a single hint can have its own. What you spend is
taken off that task's points when you pass it, never below zero.

The last hint of a task is often the full solution. Revealing it is fine; your team leader may see that you needed it.

## More time

When a lab is about to run out, **Extend** next to the timer asks for more time. A lab can be extended once, by as much
as your program allows. **Extend** doesn't show when the program allows no extension, or when the lab ends because
the schedule window or a budget cap closes.

- Usually the time is added at once.
- If the longer lab would cost enough to need a higher approver, your request goes to them, and Crucible tells you so.
  Your lab keeps running meanwhile, and the timer shows the request is pending. If they turn it down, the lab keeps its
  current end, and the extension is used up.
- An extension is also refused if the extra time would take the team or program past its budget's hard cap, even when
  it stays in the same approval tier. Only an admin can lift that.
