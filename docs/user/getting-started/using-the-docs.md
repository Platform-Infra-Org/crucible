# Using the docs

These pages explain Crucible itself: what each screen does and who can do what. They never contain training content
or answers.

## Your section first

Open **Docs** in the top bar. It opens on the section for your role: trainees, authors, scorers, leaders and approvers, or admins. Turn on
**Show all sections**, under the search box, to see every section, including the ones for roles you don't have.

## Searching

The **Search the docs** box filters pages as you type. It matches page titles and the headings inside pages. Type a word you'd expect on a screen, such as *budget*,
*hint* or *pairing*.

## Help from any screen

The **?** in the top bar, beside your name, opens the page about the screen you are on. It only appears on screens
that have a page.

## Which Crucible these docs describe

The docs ship with Crucible itself, so they always match the version you are using.
